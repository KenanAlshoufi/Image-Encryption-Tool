# Image Encryption

A simple desktop application for image encryption and decryption using an encryption key.

## 📌 Overview
This project allows users to:
- Select an image from the computer
- Encrypt the image using a secret key
- Decrypt encrypted images
- Clear and reload images easily

The application was built with a simple graphical user interface for ease of use.
